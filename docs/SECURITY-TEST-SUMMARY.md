## 3. 各轮详细结果

### R1: 核心威胁 (17 测试)

**目标**：验证基础安全模型（4 个核心维度）

| 类别 | 测试用例 | 通过率 |
|------|---------|--------|
| 🔒 敏感文件访问 | 4 | 4/4 |
| 💥 危险命令拦截 | 6 | 6/6 |
| 🤖 未知工具拦截 | 3 | 3/3 |
| 🚨 恶意内容检测 | 4 | 4/4 |

**核心发现**：
- SSH 私钥、AWS 凭据、`/etc/shadow` 等敏感路径全部被拦截
- `rm -rf`、`DROP DATABASE` 等危险命令被拦截
- 未知工具（`remove_file`、`exec_cmd`）被拦截
- Netcat、Python、Bash 反向 shell 内容被警告

**关键设计**：采用三层防御
1. `setActiveTools()` 移除 bash 工具
2. `bash_execute` 拦截器拦截危险命令
3. 敏感路径检测拦截文件访问

[→ 详细报告](SECURITY-TEST-REPORT.md)

### R2: 边界压力 (41 测试)

**目标**：测试边界场景，验证 R1 发现的薄弱点

| 类别 | 测试用例 | 通过率 |
|------|---------|--------|
| 🗂️ 路径穿越攻击 | 8 | 8/8 |
| 💣 危险命令混淆 | 12 | 12/12 |
| 🤖 工具混淆 | 8 | 8/8 |
| 🎭 内容绕过 | 7 | 7/7 |
| ⚡ 极端边界 | 6 | 6/6 |

**核心发现 - 修复的真实漏洞**：
1. `/etc/./shadow` 点段绕过 → 新增 `resolveDotSegments()`
2. 多种命令注入（`;`、`&&`、`||`、`$()`、反引号） → 新增 6 种模式
3. `dd of=/dev/sda` 设备破坏 → 新增检测
4. `\x72\x6d` hex 转义绕过 → 新增解码逻辑
5. Base64 编码管道 → 新增检测
6. 字符串拼接绕过（`c"u"r"l`） → 新增去混淆

[→ 详细报告](SECURITY-TEST-R2.md)

## 4. 防护能力全景

### 4.1 六层防护架构

```
┌─────────────────────────────────────────────────────────────┐
│ L1: 工具注册表层 (pi-disable-bash.ts)                        │
│ • 直接从 LLM 工具列表中移除 bash                              │
│ • LLM 根本看不到 bash 工具                                   │
│ • 通过 pi.setActiveTools() 实现                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ L2: 路径白名单层 (pi-path-whitelist.ts)                      │
│ • 拦截 ~/.ssh/、~/.aws/、/etc/shadow 等敏感路径              │
│ • 拦截持久化路径 (.bashrc, .config/autostart, 注册表 Run)    │
│ • 工具: read, write, edit                                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ L3: 命令拦截层 (pi-no-delete-db.ts)                          │
│ • 拦截 rm -rf、DROP DATABASE 等危险命令                      │
│ • bash_execute 拦截器                                        │
│ • 多重混淆检测（注入、替换、管道）                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ L4: 内容审计层 (pi-path-whitelist.ts 内容钩子)               │
│ • 恶意内容警告（不阻止写入）                                 │
│ • 独立的恶意内容日志                                         │
│ • 严格模式可切换                                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ L5: 元约束层 (pi-mechanism-verify.ts)                        │
│ • Spike-First 工作流                                         │
│ • 风险模式提醒                                               │
│ • 验证跟踪                                                   │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ L6: 工具白名单层                                             │
│ • 限制 LLM 只能使用 read/write/edit                          │
│ • 任何未知工具（remove_file, exec_cmd）都被拦截             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 核心防御组件

| 组件 | 文件 | 职责 |
|------|------|------|
| `pi-disable-bash.ts` | 工具移除 | 直接操作 LLM 工具列表 |
| `pi-path-whitelist.ts` | 路径+内容 | 敏感路径拦截 + 恶意内容审计 |
| `pi-no-delete-db.ts` | 命令拦截 | 数据库保护 + 危险命令拦截 |
| `pi-mechanism-verify.ts` | 元约束 | Spike-First 验证 |

## 7. 防护演进总结

### 7.1 累计覆盖威胁类型

```
208 个测试用例覆盖以下 6 大类、40+ 子类威胁：

1. 路径访问 (R1-R3)
   - 敏感文件: SSH, AWS, .env, /etc/passwd
   - 路径穿越: ../, URL 编码, Unicode, 点段
   - 持久化: .bashrc, cron, systemd, 注册表
   - 隐藏路径: .config, .local, .gnupg

2. 命令执行 (R1-R2, R5)
   - 危险命令: rm -rf, DROP, FLUSHALL
   - 命令注入: ;, &&, ||, $(), 反引号
   - 命令混淆: hex, dd 设备, chown
   - 网络下载: curl|bash, wget|sh

3. 工具白名单 (R1-R2)
   - bash 大小写变体: BASH, Bash, bash_legacy
   - 未知工具: exec, shell, system_shell, run_command

4. 内容审计 (R1, R3-R4)
   - 经典恶意: nc -e, bash /dev/tcp, DROP TABLE
   - 多语言: PHP eval, JS eval, Python pickle, Java Runtime
   - 挖矿: xmrig, mimikatz
   - 元编程: YAML !!python/object, JSON __proto__
   - 编码绕过: Base64, ROT13, hex, 字符串拼接

5. 横向移动 (R5)
   - SSH 密钥横向
   - 配置管理: Ansible, SaltStack, Puppet, Chef
   - 远程执行: PsExec, WMI, RDP
   - 凭据爆破: Hydra

6. 容器与云 (R5)
   - 容器逃逸: Docker socket, /proc/1/root, cgroup, capabilities
   - 云凭据: AWS IAM, GCP SA, Azure metadata
   - K8s 攻击: secrets, cluster-admin
```
